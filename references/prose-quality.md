# 正文质量：情境、感知、标点、段落与文风

起草、续写和语言修订时读取。本文件约束叙事判断，不按词语命中判错。作者指定的视角、语言和排版优先；“减少 AI 味”按具体写作质量处理，不作作者身份判断或检测通过承诺。

## 生活细节必须放回具体情境

首次出现的细节也要检查可信度。先确定故事的时代、地域、人物生活方式和眼下活动，再判断衣着、携带物、支付通信方式、作息和社交反应是否贴合。不要直接套用题材常见的装备清单、生活流程或人物反应；“拥有某物”“某类人常用某物”和“此刻带在身上”是三个不同判断。

发现可疑细节时区分：

- **现实条件或已建立状态不支持：** 检查动作所需的位置、身体条件、工具、时间与资源。关键条件缺失会使后续结果失去依据，应修订或按设定补足真实发生的变化。
- **不典型但可能：** 生活习惯受年代、地区、职业、年龄与个体影响。不能把“少见”当成“不可能”，也不能用少数可能性替任何随手生成的细节辩护。无特殊用途时采用贴合本场景的普通做法；若异常习惯对情节重要，用自然且足够的行为或背景支撑。
- **尚不确定：** 涉及专业操作、历史制度或有时效的现实细节，且结论会影响情节时，查询可靠资料或明确保留未知；不要用作者自己的习惯冒充常识。普通生活动作不必逐项查资料。

审稿时沿实际动作顺序走一遍，问“这个人刚做过什么，现在处于什么状态，下一步凭什么能这样做”。对突变、出行、逃生、受伤和物品盘点尤其要回看最近场景。具体状态交接见 [连续性契约](continuity.md)。第一章同样执行，不能以没有前文正史为由跳过。

发现问题先调整不必要的细节或当前动作。普通、容易推知的日常步骤可以省略，不要求写流水账；但跨越明显状态差异、产生有利资源或决定成败的步骤不能只靠省略成立。不要用一句“幸好”“原来早就”“恰好”临时补出习惯、装备或过去事件。幽默旁白也不能代替因果依据。

幻想设定可以改变现实条件，但例外应有明确范围，并在范围外继续遵守日常与物理约束。若主角把异常当成谜团，正文需让读者意识到这是有意留下的问题；在解释前，不能把它当作已证明合理的便利条件反复使用。

## 人物只能回应自己能获得的信息

区分四层：客观发生的事、叙述者能讲的事、读者已读到的事、每个人物已知或相信的事。全知叙述可以告诉读者秘密，不能因此让在场人物也知道秘密。

对会触发识别、纠正、判断或行动的台词与反应，检查“信息来源 → 感知渠道 → 人物理解 → 反应”是否连贯：

- 听见的话只提供声音、语义和可听出的语气；字形、标点、引号、括号与叙述标签不属于声音。文字差异需要看见文字、口头拆字说明或已建立的共同知识。
- 看见的东西受距离、遮挡、光线和观察时间限制；不能自动获知名字、材质、内部结构或真实意图。
- 转述、推测、误解和撒谎可以存在。保留其来源与不确定性；别让猜测无证据地变成叙述事实，或让另一人准确回应没有说出口的心理活动。
- 特殊感知、系统提示、职业经验和预先获知的信息必须有设定或文本依据；私有界面默认不向其他角色共享。不要为补洞临时发明能力或共同经历。

局部错误优先改当前草稿中的言行，使其符合已有信息；如果修复依赖新增的重要设定，再按创作权限处理。不要把每句对白都补成解释信息来源的说明书。审稿时从听者或观察者的位置重读关键交流，暂时排除读者才看得到的信息。

## 中文标点

未另行约定时，中文正文使用全角标点：`，。：；？！“”‘’（）《》……——`。对白用 `“ ”` 包裹，引文内再引用用 `‘ ’`；省略号作 `……`，破折号作 `——`。数字、单位、英文、代码与 URL 内部保留半角（如 `3.5%`、`APP`、`12:30`、`don't`），不因相邻汉字改写。`设定集/文风契约.md` 明确指定其他方案时（如竖排引号 `「」`，或作者刻意保留的半角风格），以作者约定为准，并在审稿记录中注明依据。

起草时直接按此书写；语言修订时统一核对，机械替换前先确认命中处不在英文语境。提交结算时脚本会拒绝与汉字相邻的半角标点，作者明确接受的半角风格须先记入文风契约。

## 面向手机的段落节奏

未另行指定时，以短段为主：一段承载一个动作节拍、一个观察焦点或一轮意思相连的发言，常见长度为 1–3 句。这里是起草倾向，不是字数、句数或屏幕行数的硬限制。

- 非对白段落包含多个完整句时，默认逐个检查句号后的分段机会；相邻句切换了动作主体、观察焦点、信息点或节奏重心，通常就在句号后另起一段。共同完成一个连续动作、观察或情绪蓄势的句子可以保留在同一段，不机械地“逢句号必换行”。
- 更换说话人必须另起一段，不把两个人的台词写在同一段内。说话人与台词的归属应清楚，必要时使用简短的动作、称谓或提示语标识。
- 动作与台词交替时，可用错落分段强化冲突和节奏：先写一方动作，再另段写其台词；换到另一方时同样另起动作段与台词段。同一人的短动作与短台词若属于同一节拍，也可以相连，避免把普通交流拆得过碎。
- 角色连续讲述背景、规则或立场时，每两三句检查一次阅读呼吸：可插入说话人的停顿、动作、视线变化，或其他在场者有信息量的反应，再继续台词。插入内容应反映关系、压力或理解变化，不能为了凑节奏反复喝水、点头、环顾四周；若打断会破坏语意和情绪，可以延后到自然停顿处。
- 动作转折、注意力切换、时间推进或信息落点适合分段。若一个段落同时承担环境介绍、回忆、规则说明和当前行动，优先压缩、移位或重组，再分段。
- 连续长段需要检查手机阅读负担；完整的情绪积累、连续观察或有意放慢的段落可以保留。
- 避免整章“一句一段”、每个短语独占一段、靠空行制造虚假悬念。短段应有长短起伏，拆段后仍需检查指代、动作归属和对白节奏。

不要只在交稿时机械加换行。信息密度过大时，拆成几个段落仍然会累，需要调整内容本身。

## 减少模板感的写作与修订

先读取 `设定集/文风契约.md`。记录视角距离、叙述语域、解释密度、段落倾向、人物说话方式，以及作者接受或否定的表达习惯。已有作者认可的正文时，选少量相关片段作本书的尺度；新书暂无样本时先使用简洁、具体的暂定基线，不为填契约反复打断作者。不要从模仿某位作家的口吻建立文风。

写作时让用词来自当前人物的目的、经历、处境和注意力。对白允许回避、试探、抢话和答非所问，但须有关系或情境依据；不能让所有人物轮流替作者讲规则、复述情节或发表同一种漂亮议论。

初稿后单独做一次语言修订，连读本章和前一至两章的相关段落，检查反复出现的叙述习惯：

| 可观察的问题 | 修订方向 |
|---|---|
| 动作或对白已表达情绪，旁白又解释情绪、意义和人物性格 | 删去读者已能推知的复述，保留理解因果所需的信息 |
| 抽象评价、万能感官描写、比喻可以原样移到任意人物或场景 | 换成此人在此刻会注意、会取舍的具体内容；无作用则删 |
| 对话过分完整、对称，所有人都说同一种长句 | 按各自的目的、身份关系和已知信息重写，保留必要的不直说 |
| 连续使用同构排比、转折、反问或断句，章章相似 | 改变信息展开和动作节奏；不用同义词替换掩盖重复结构 |
| 每段总结意义，每场拔高主题，每章末尾预告命运 | 在行动、代价、尚未回答的问题或关系变化处自然结束；允许局部收束 |
| 信息很多但没有选择、阻力或结果变化 | 回到场景推进修订，单纯润色句子无法解决 |

某种句式、修辞或总结偶尔有效，不设禁词表，不规定每章配额。不要靠随机口语、错别字、无意义碎句或堆砌生活细节模拟“人写”。修订后再次核对事实与知识边界，避免语言变体改变实体性质、人物确定程度或信息可见范围。
