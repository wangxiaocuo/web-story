# 上下文策略

长篇小说的正文不是默认上下文。为每次工作生成一份临时的 context pack，列出读取文件和选择原因；不要把它当成正史或提交产物。

## 加载层级

| 层级 | 内容 | 何时加载 |
|---|---|---|
| L0 | 用户本轮目标、目标章节 | 始终 |
| L1 | `创作简报.md`、`文风契约.md`、确认事实、`current-focus.md` | 写作、规划、重大修订 |
| L2 | 当前章节意图、前一至两章全文 | 起草或续写 |
| L3 | 与本章实体有关的事实、时间线片段、开放伏笔、分卷摘要 | 按任务检索 |
| L4 | 远期大纲、遥远正文、无关素材 | 仅有明确依赖时 |

## 规则

- 修改某一章时，完整读取该章；若修改人物、线索或回收，额外读取受影响的相邻章节与事实来源。
- 正文与结构化记录不一致时，将正文视为待核验的证据，报告差异；不得静默改写其中任一方。
- 角色知识、读者知识、客观事实分别处理。人物不能因作者知道而知道；读者也不能因摘要存在而知情。
- 若 L1–L3 不足，按实体、章节或事件精确扩展；不得为了“保险”加载整部小说。
